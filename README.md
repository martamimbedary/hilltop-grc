# Hilltop Guest House
This repository is for a formal governance, risk and compliance (GRC) foundation to meet ISO 27001 requirements and demonstrate security maturity to partners.

## Overview
**Clent:** Hilltop Guest House.
* Hilltop Guest House is a boutique hotel with 20 rooms, a small restaurant, and an online booking portal.
* Wants formal GRC foundation to meet security maturity under ISO 27001.

**Goals:** Deliver a complete ISO 27001‑aligned GRC package, from asset inventory to published policies, hosted on a live GitHub Pages
site.

## Deliverables
- GitHub repository containing all artefacts and a README
- Asset inventory CSV file with realistic hotel assets
- ISO 27001 gap analysis report (Markdown)
- Risk register spreadsheet (CSV) with risk scores
- Core security policies and control implementation plan (Markdown)
- Live GRC package published on GitHub Pages (public URL)
